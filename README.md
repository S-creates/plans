# plans

Standalone visual artifacts for training and nutrition planning.

## Zero-equipment recomposition blueprint

Open `index.html` in a browser to view the visual 4-week plan.

It includes:

- Hand-and-palm portion guide for a 185 cm / 95 kg male
- Swedish grocery meal examples using ICA, Willys and Coop staples
- Jawline and water-retention rules
- Full 4-week arms, chest, shoulder, back and core home program
- Exact Workout A/B/C/D cards with sets, reps, rest, cues, easier versions and harder versions
- Safer setup guidance for door-frame, table and chair movements
- Regressions and progressions for each key movement
- Daily habit checklist
- Print / Save PDF button

The page uses Mermaid and Chart.js from CDNs for the system map and progression visuals. The core plan still works as a normal static HTML page if opened offline.
